# Albion Online - Discord Ping Bot

Bot de Discord para alertas y pings de Albion Online. Online 24/7.

## 🚀 Funcionalidades
- Sistema de Pings: Notifica a roles con /ping 
- Alertas de ZvZ / Gank / CTA
- Persistencia en pings.json
- Comandos Slash

## 📁 Estructura
├── main.py
├── discloud.config
├── requirements.txt
├── pings.json
└── README.md

## 🛠️ Instalación Local
1. git clone https://github.com/TU_USUARIO/TU_REPO.git
2. pip install -r requirements.txt
3. Configura TOKEN=tu_token
4. python main.py

## ☁️ Deploy en Discloud
1. GitHub -> Discloud -> Add App -> GitHub
2. Activa usar discloud.config
3. ENV: TOKEN=tu_token_real

## 📜 Comandos
/ping | /setup | /help

## ⚠️ Notas
Nunca subas tu TOKEN real a GitHub.
